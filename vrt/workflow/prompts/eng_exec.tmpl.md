# 你必须完成的工作

1. 阅读任务书，完成任务规定的工作（含代码/脚本/实验等实际改动）；
2. 将工作成果写入 `{{RA_DIR}}/steps/step_{{STEP_INDEX}}_result.md`，逐项对照验收标准，记录实际改动、实验命令/参数、退出码、原始数据、证明或证伪结论及其适用范围。测试未实现、未启动、未完成与测试失败必须区分；静态计数不能替代动态运行。失败后应定位并尝试修复、缩小复现或替代验证；仍受阻时记录实际错误、已尝试办法及可接续的最小任务，不能用预计耗时或缺少尚待实现的接口证明方向无价值；
   成果文件必须单独写出：`VRT_PRIMARY_PROGRESS:`（主目标推进了什么）、`VRT_EVIDENCE:`（可核查证据及命令/退出码）、`VRT_REMAINING_GAP:`（距完整目标还缺什么）。
3. 实验日志和临时工作流文件保存在仓库 `ptmp/`，构建产物遵守仓库既有目录规定，不放入 vrt/。报告保留关键数据、相对仓库的证据路径、输入与版本指纹，供 RA 核查；不提交大型产物；
4. 提交改动。
