A0021 给 t2 留的唯一可重访 commit 形态是「commit 内锥输入侧快照检测（读侧）」，
并规定「正式评估前必须离线量化且门槛 >=3%」。本 action 先在 s06-c1 分支实现了

离线静态量化：

- 初版（沿用 dirty 制度的 64 叶上限 + W>=2L 成本筛选）：真设计 emit **gated=0**
  ——bails 为 unsafe=807 / 叶数>64 47 / 成本 2119，全部 2,973 个 commit 块被拒。
- 放宽到读侧校准（256 叶上限 + W>=L，已随实现提交）：gated=1,246，但仅覆盖
  6,363 个快照叶、保护 **8,842 条指令 / 3,058 个状态写**——是 e00019 dirty 模式
  保护面（440,821 指令 / 162,422 写站）的 **~2%**。
- 拒绝结构：unsafe=807 块持有 116,998 写（宽/非标量叶在 snapshot 模式无 tracked
  桶兜底，整块拒）；成本拒 900 块。被接受的门 W/L 均值仅 ~1.39，盈亏裕量薄。

裁决依据（静态覆盖即决定性）：读侧快照即使完美跳过其全部保护面的幂等工作，
上限也只有写站的 ~1.9%，远低于 3% 门槛；大叶数是 commit 块的结构属性
（锥宽），不是筛选参数能绕过的。**读侧快照形态按 A0021 纪律不正式评估，
commit 内锥检测轴以定量证据关闭**（代码保留默认 off 供 restart 参考）。

## 机制分析与裁决

**c2 的旋钮没有接合，意外成为安慰剂对照。** e00038 的 emit 日志出现
`optimize skipped (gsim node-aligned)`——本设计的调度是 gsim node-aligned，
整个 optimize（含 tree-atom-fold）被跳过，`--tree-atom-fold-max-instr 8` 是
惰性参数。产物核验：e00038 与 e00019 的 emit 目录逐文件 diff 仅
`grhsim_SimTop.hpp.pch`（含构建路径/时间戳的预编译头）不同，其余 1.71GB 生成
代码逐字节一致——**e00038 就是 e00019 代码在当日机器上的重测**。atom 粒度轴
不能经此旋钮触达（要触达须先解除 node-aligned 对齐，那是另一个实验条件），
本路径关闭。

**安慰剂暴露跨日漂移 ~2.6%，c1 的「确认」被推翻。** e00019 代码 8-17 实测
264.466s，8-19 重测 257.629s——同一二进制语义相差 2.58%，远超协议内 CV。
同日对照才是有效比较：e00037 257.300s vs e00038 257.629s = **-0.13%**，
rep 区间（253.2-257.9 vs 257.4-261.0）高度重叠。**affinity+消零+commit 门控
组合相对门控单机制为亚噪声中性**，c1 假设（>=1.5%）不成立；e00019 的
-1.95% 与 e00020 的 -1.66% 的可加性问题在本协议分辨率下不可裁。登记时
e00037 的 insight 按名义 -2.71% 写了「确认」，此处勘误（ledger append-only，
以本笔记与 insights.md 勘误条目为准）。

**裁决与 adopt 注解。** 机械 winner = e00037（-257300 vs -257629，差 0.13%
为噪声级），已入 `tes/r001/t2/main`；run.json 的 t2 best 字段随之变为 e00037，
但同日证据表明它与 e00019 代码等价——**noise-level adoption，非机制收益**
（同 e00008/e00025/e00031 先例）。附带实质收益是编译侧：t2/main 此后携带
`--init-zero-elision --state-layout affinity`，emu_build 845s→296s（-65%），
t2 的评估时延与编译预算裕量大增（e00037 compile_s=623.9s vs e00038 1172.6s）。
若后续证据显示 affinity 有害，回撤路径 = emit_args 摘除两个旋钮（代码默认 off
逐字节等价）+ 重测。

**测量纪律新刻度。** A0006 记过同代码 run-to-run 全距 ±1.5%；本次同代码跨日
差 2.58%（264.466→257.629）。**凡对照点与候选不同日测量、且名义差 <3% 的
裁决一律存疑**；t2 历史结论中 e00019（-1.95% vs 8-15 的 e00014）等跨日弱正
均需按此刻度重新审视，restart 前应以同日重测校准。
