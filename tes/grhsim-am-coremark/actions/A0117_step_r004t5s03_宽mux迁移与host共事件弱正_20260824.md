## 裁决与机制分析

- `finish-step` 按 raw score 选择 e00121，并把 `80c4657` 快移到 t5/main；但相对父
  e00110 的 **2.81%** 改善仍在 r004 的 +/-3% 噪声带内，因此 outcome=`neutral`，
  t5 统计 best 仍保留 e00110 **173.058s**。分支 tip e00121 为 168.198s，较冻结 AM
  e00085 改善 **13.03%**，冻结 gsim/e00086 口径为 **7.403x**，仍比全局 best
  e00113 166.014s 慢 **1.32%**。
- 宽 mux 迁移在 t5 得到第四种组合背景下的正向信号：4/92 生产命中稳定，增量
  2.81% 接近但未越确认线。它明显强于 c2，且方向与 e00106/e00113 一致；不过不能
  将本次单窗结果升级为新的 confirmed 节点。
- common-event run 静态覆盖 **12,607** 个 host call，说明它不是安慰剂；Host 改善
  1.36% 证明“一次外门跳过长串重复 event 判断”有弱正信号。但目标动态池还包含
  b90656 的 enable 计算，且 event 为真时内部逐站 enable 分支仍全部保留，解释了
  4.702% 池只兑现有限整体收益。没有 post-change recon，不能宣称 b90657 达到
  预注册的 20% 池级降幅。
- c1 比 c2 快 **2.510s（1.47%）**，低于 3% 机制分辨带；raw winner 不足以断言两种
  机制的真实差距。预算从 36/48 增至 **38/48**，全局 best 保持 e00113。
