## 机制分析

- 分支消除 + 向量化成立（静态形态确切变化），运行时却回退 1.71%：
  **内层分支误预测不是该族的主导成本**。回退来源嫌疑 = 恒写的代价：
  未变更槽不再跳过 store，目的 cache line 无条件变脏（每 eval commit 相
  ~1.4MB 目的流全部 dirty → 驱逐写回流量增加）；向量化把 4,096 event 压成
  直线码同时把「跳过未变更写」的选择性彻底丢掉。
- 与 t0 A0041「宽站 detect 成本数据侧 miss 主导、省指令无效」互证并外推：
  **窄站写口阵列同样是数据侧主导**——分支结构（误预测）不是一阶项。
  commit 写点检测分支结构轴关闭；commit 相残余开放方向只剩纯数据侧
  （布局/预取类），且需面对 194MB 流扫下预取仅移动 miss 不消除流量的
  带宽约束。
- 机制面 = emit 规则变更（emitter 开关），文档条目随候选提交
  （grhsim-am-pipeline.md `commitWriteBranchless`）；候选分支保留可复现。
