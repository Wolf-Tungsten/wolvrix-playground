c1 的失败是候选测试契约错误。失败后只读取 ctest 生成物取证：lazy 模型中

性能测量；scratch 后延机制在本 step 是**未测**，不是性能证伪。

c2 同样是候选测试期望错误。stock、outline、predicate-run 三个 harness 输出逐字节

`if ((v1 != 0))` 内且顺序不变。测试把 data 数写死为 9，导致等价输出仍失败。
谓词 run 机制因此也是**未测**，不能据本 action 判断 b90656/b90657 的收益。
