## 跨轨迹机制结论

### 收敛信号

- **activity 扫描剪枝 x 定向状态 locality 是 run 内最强可叠加轴**：e00027 在
  word 层 guard 之上叠加 wide first-touch 再收 3.43%，与 round 4 的 e00021
  （part 层 guard + first-touch，-3.27%）一致——两级扫描剪枝都不吞没定向布局
  收益。t0 借此把 run best 推进到 222.654s。
- **常量生命周期呈 read -> storage 层级，且各层独立可收**：t1 的 e00024（常量
  读取内联，-1.20%）之后，e00030（安全常量 backing storage 与 init store 删除）
  再收 4.52%，为本轮最大单步改善；e00029 的 divmod 内联（-1.64%，CV 0.09%）
  是稳定弱正。生成 C++ 的状态对象瘦身是继 helper 调用边界后 t1 的第二个一阶池。
- **t0/t1 经不同机制路径收敛到相近数量级**（222.7s vs 230.4s，差 3.4%）：t0
  走扫描剪枝 + 定向布局，t1 走 helper/常量内联 + 状态瘦身，两者均只动生成
  C++ 适配层、不改 AM schedule 工作量，机制正交。这是 restart 时跨轨迹组合的
  明确材料（当前 run 保持轨迹独立，不组合）。

### 发散与关闭信号

- **t2 的 commit-input gating 静态/准静态细化全部关闭**：继 e00025（全局
  dirty-edge 阈值）与 e00026（宽态炸开组合）之后，e00031（位图压缩）亚 CV 无
  收益证据、e00032（producer 输出快照）+7.98% 明确回退，四连未改善 e00019。
  覆盖、静态边数、存储压缩、producer 侧真变化过滤都不是动态净收益代理；重开
  条件不变——逐 gate 动态 open/skip、传播 store 与实际跳过工作量的净收益证据。
- **word 局部 snapshot 证伪**（e00028，+2.19%）：word guard 收掉空扫描后，
  全局 activity word 的载入/清除访存量不是独立热成本；局部 `wordFlags` 引入的
  控制/数据依赖反而退化。扫描路径的进一步本地化（连续空 word summary 等）必须
  先有离线 open/skip 与有效 byte 分布证据。
- **机械 winner 边界再现**：e00031 以 +0.30%（亚 CV）入 t2/main，无害前提是
  packed-dirty 默认 off（emit 不携带即语义不变）。t2/main 现已携带两个未证实
  的默认 off 实现（sparse 阈值、packed dirty）；后续 t2 候选 emit_args 不得
  携带它们，除非先有动态净收益证据。
