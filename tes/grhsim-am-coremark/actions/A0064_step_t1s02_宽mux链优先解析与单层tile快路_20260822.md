# A0064 - r003/t1/s02 宽 mux 链优先解析与单层 tile 快路

## Action 与出发点

- action: `step`，run `r003`，trajectory `t1`，step `s02`，`K=2`。
- Phi 节点: `e00056` (`014c3aefa3b4`)，`--wide-mux-chain-fuse`，Host 中位
  `241956 ms`，`compile_s=1986.6`，17/17 ctest 和 3-rep difftest 全过。
- 病灶取证: `e00056` 生产 emit 共 156 条融合链 / 247 levels / 74 blocks；
  长度分布为 151x1、1x4、4x23。现 helper 对每个输出 word 重放所有
  level，且单级链仍构造 `chain_sels` / `chain_tvals` 指针数组并进入通用
  level loop。

## 候选预注册

### c1 / e00059: 多级链高优先级位图解析

- 来源节点: `e00056`。
- 反馈/病灶: 4 条 23-level x 352-lane 链加 1 条 4-level 链在现 helper
  内做 `words * levels` 次指针追踪、select bit 提取和 blend；但每个 lane
  最终只需最高优先级命中的一个值。
- 局部改动: 新增默认关的显式 emit 开关
  `--wide-mux-chain-priority-resolve`；仅对 `levels >= 2` 的已融合链按
  64-lane tile 从高优先级向低优先级扫 selector mask，用 unresolved
  mask 保证每个 lane 只写一次；单级链与旧 helper 不变。
- 可证伪预期: 功能门全过且 Host 相对 `e00056` 至少降低 2%
  (中位 `<=237117 ms`)；低于 1% 或回退则证伪。编译必须保持
  `compile_s <= 2400`。

### c2 / e00060: 单级链 tile/scatter 快路

- 来源节点: `e00056`。
- 反馈/病灶: 151/156 条链只有一级；现路径为单次 mux 仍在调用点
  构造两个指针数组，通用 helper 内按 lane 反复加载同一 selector word。
- 局部改动: 新增默认关的显式 emit 开关
  `--wide-mux-chain-single-level-tile`；单级链直接传 sel/tval，每 64 lane
  只读一次 selector mask，整 tile 复制/填充 base 后仅覆写 set-bit lanes；
  多级链与旧 helper 不变。
- 可证伪预期: 功能门全过且 Host 相对 `e00056` 至少降低 1.5%
  (中位 `<=238327 ms`)；低于 0.5% 或回退则证伪。编译必须保持
  `compile_s <= 2400`。

## 裁决

`finish-step` 按 score 机械选择 **c1/e00059**（score `-257235`），已快移入
`tes/r003/t1/main`，t1 tip 为 `d28a44f`。c2 分支按 retention 规则保留。

## 机制分析

- c1 确实将多级链的 selector 读从逐 lane 重放改为每 64-lane tile 一次，
  但仅命中 5/156 条链，且引入 `countr_zero` 位枚举、unresolved 控制依赖
  和分散 store。对 e00056 的冻结读数名义回退 6.32%，未达 2% 改善预期；
  本轮没有产生该快路的正收益证据。回退量是跨窗口数字，不将全部
  6.32% 强归因于机制。
- c2 的覆盖与预注册精确一致，但 `e00060/e00059 = 1.393x`，正落在
  r002/r003 多次观测的 1.3-1.4x per-process 快慢态带内。因此 raw score
  上机械落败，但不能把约 39% 的 c2/c1 差值归因于 tile/scatter；它同样
  没有给出正收益证据。
- 两项实验共同指出：仅凭静态 chain/level 数不足以决定 helper 微结构。
  下次重开条件是先量化 5 条多级链的动态 block execs、selector 密度与
  旧 helper 在生产二进制中的实际分支/向量化形态；在没有这类证据前，不原样
  重测 priority-mask 或 single-level tile 变体。
