## 裁决与下一步建议

本 recon 成功刷新 r004/t3 的动态证据，功能门通过且不消耗 eval-id。

1. 对“索引位宽恰好覆盖 2 的幂深度”的 memory read 发射专化：直接提取并掩码
   窄标量索引，去掉通用 `index_words` 和不可达的越界分支。要求生产 engagement
   覆盖上述六块的 3,072 个站点；可证伪预期是该池 cycles 至少下降 25%、整体
   Host 下降至少 0.75%，低于 0.25% 则关闭该形态。
2. 对严格相邻的 22,528-bit broadcast-to-mux 链做单 pass 融合，以标量 true-value
   直接选择并只物化最终 352-word 结果。要求同时覆盖 b69157/b69158/b69159；
   可证伪预期是三块 cycles 至少下降 70%、整体 Host 下降至少 0.75%，低于 0.25%
   或仍物化逐层中间数组则证伪。
