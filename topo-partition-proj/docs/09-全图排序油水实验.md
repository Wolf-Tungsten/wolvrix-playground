# 09 全图排序油水实验（R1 预案，Phase 2 go/no-go 输入）

2026-07-30。Phase 1 的区域证据（docs/08：规范序在区域层面贴近 CP-SAT 精确最优、
512 区域标签相对规范序 median 改善 0.0%）留下一个决定性问题：**排序的价值是否藏在
区域边界之外的全局结构里**（风险登记 R1）。按 R1 预案，在 openc910 这种较小设计上做
全图搜索实测差距。本文记录 as-built 流程、数据与结论。

实验问题：在**没有任何冻结边界**的完整指令图上，"排序"这个自由度相对确定性规范序
（Kahn + 最小 id 平局规则）还有多少油水？答案直接决定 Phase 2 的 GNN 是否值得做。

## 1. c910 数据集导出（环境迁移后的 as-built 流程）

本机为新迁移环境，补齐的依赖与踩过的坑：

- wolvrix C++ CLI 未随迁移带来：`grhsim-am-lower-json` 目标不在 pip skbuild 构建里，
  需全量配置构建（`CC=clang CXX=clang++ cmake -S wolvrix -B wolvrix/build-cli`，
  二进制在 `wolvrix/build-cli/bin/`）。
- `.venv` 里的 wolvrix python 包是旧版：`scripts/wolvrix_xs_grhsim.py` 调
  `reg-to-mem` 的 `decoded_write_storage`/`ordered_writes` 参数被拒，需
  `pip install --no-build-isolation -e wolvrix` 重装（scikit-build-core 需
  `CMAKE_GENERATOR="Unix Makefiles"`，否则 slang 的 FetchContent 子构建会拿 ninja
  去跑 Makefile 报错）。
- c910 filelist 解析纪律：slang 把 `-f` 嵌套路径相对 CWD 解析，CWD 必须是
  `testcase/openc910/smart_run/logical`；`ip.fl` 里的 `${CODE_BASE_PATH}` 指向
  `testcase/openc910/C910_RTL_FACTORY`。

导出链路与香山同构（`sim_wolf.fl` + top `sim_top`）：

```
# 1) RTL → post-stats GRH JSON（legacy 归一化脚本，env 同香山）
scripts/wolvrix_xs_grhsim.py filelists/sim_wolf.fl sim_top <normalize_dir> "" \
    <read_args> info --waveform off --perf off   # + WOLVRIX_XS_GRHSIM_* env
# 2) GRH JSON → AM 下降 + 生产调度，导出指令图与生产划分
WOLVRIX_GRHSIM_AM_INSTRUCTION_GRAPH_JSONL=.../instruction_graph.jsonl \
WOLVRIX_GRHSIM_AM_BLOCK_ASSIGNMENT_JSONL=.../block_assignment.jsonl \
wolvrix/build-cli/bin/grhsim-am-lower-json c910_post_stats.json sim_top --emit <dir>
```

产物 `exp/dataset/c910_full_20260730/`：

- 指令图：1,117,370 节点（1,081,280 非 commit）/ 1,871,034 def_use /
  477,750 external_read / 642 order 边；`comb_loop_atoms=0`（与香山一致，
  真实电路 SCC 收缩是恒等映射）；Kahn 全排，DAG 成立。
- 生产划分：15,765 blocks（8,487 compute + 7,278 commit），plain 基线
  cost = **5,343,459**，dag_edges 128,669，ccvp 782,245。

## 2. 确定性基线（plaindp，D5 第二对照的全图版）

`run_fullgraph_plaindp.py`（规范序 + 段 DP、去 coarsen、commit 侧沿用生产块）：

| 指标 | 生产 plain | no-coarsen 规范序+DP | Δ |
|---|---|---|---|
| cost | 5,343,459 | 5,101,136 | **−4.5%** |
| dag_edges | 128,669 | 89,453 | **−30.5%** |
| ccvp | 782,245 | 601,694 | **−23.1%** |
| footprint（块数） | 15,765 | 17,757 | **+12.6%** |

与香山同型：cost 降、dag_edges/ccvp 显著更优、footprint 越红线（128 硬容量所致，
λ=2–4 段惩罚可部分回收，见 docs/08 §5）。c910 上 dag_edges/ccvp 的改善幅度比香山
大得多（c910 生产侧 commit 块占比高，结构不同），footprint 抬升幅度相近。

## 3. 全图 SA：从规范序出发（主实验）

`run_fullgraph_search.py`：段 DP（C 内核，0.5s/次 @n=1.08M）逐提案精确重算；
移动集、合法域、温度标定与区域搜索器完全同构（`harness/fullgraph.py`，
单测 `tests/test_fullgraph.py`）。32 链 × 2000 迭代（共 64k 次提案，
温度标定 t0=3.72），`fullgraph/fullgraph_search.json`：

- 规范序 cost = 5,101,136（与 plaindp 工具逐分一致，交叉验证通过）；
- **最好链 = 5,101,052，改善 0.0016%**；25/32 条链零改善；各链接受约
  620–680 次移动但几乎全是等值/回摆——规范序邻域是极平的谷底；
- 最优序合法性机检：违序边 0。

## 4. 零假设探针：随机线性扩张

若 cost 函数对排序结构性不敏感，"排序油水"问题根本不存在。8 条随机合法拓扑序
（Kahn 随机平局）实测 cost 6.749M–6.772M（均值 6.762M）：

- 随机序比规范序差 **+32.5%**，且彼此间离散仅 0.3%；
- 结论：cost 对全图排序**高度敏感**，但敏感度的绝大部分被"任何像样的确定性
  Kahn"拿到——规范序离"随机合法序"的距离，比离局部最优的距离大四个数量级。

## 5. 盆地结构探测：从随机序出发的 SA

主实验只从规范序出发，理论上存在"局部移动够不到的远处深谷"。补 16 链 × 5000
迭代，每链从一条新的随机线性扩张出发、独立标定温度
（`--start random`，`fullgraph_random/fullgraph_search.json`）。

**结果：没有任何链爬回规范序。** 16 条链起点 cost 6.750M–6.775M，各自接受约
3.5k 次移动（接受率 ~70%，基本在高温随机游走），终点 best 6.750M–6.774M——
相对各自起点仅改善 **~0.01%**，全部停在比规范序差 +32.3% 的水平上。

解读要分清两件事：

1. 这**否证了**"cost 地貌是单一盆地、随便从哪出发都能爬回规范序"的强假设。
   随机序所在的高原本身也是局部平坦的（单点移动在 5000 次预算内同样找不到
   下坡方向）——地貌是"到处局部平、整体落差 32%"的崎岖形态。
2. 但它**不能**反推出"存在比规范序更好的远处深谷"。从随机序到规范序质量的
   差距需要大比例节点的协同移动，5000 次提案（0.005 次/节点）远不足以跨越；
   链爬不动是移动预算与地貌崎岖度的体现，对"深谷存在与否"不提供证据。
   规范序起点 64k 次提案找不到更好解（§3）+ 区域级 CP-SAT 精确最优（docs/08
   §2）才是"规范序之上无油水"的正面证据。

采样方法说明（应 reviewer 问）：随机线性扩张用 Kahn 随机平局生成，它不是线性
扩张的均匀采样（三元例可证偏差，如 bac 被高估 1.5×）。对本实验两个用途影响
有限：§4 零假设探针中 8 条序的 cost 离散仅 0.3%，偏差要拉偏 100 倍离散度才
能动摇结论，且偏差方向（若有）是低估真实差距、使结论偏保守；§5 中起点分布
偏差不影响"SA 从起点能走到哪里"这一观测。严格的均匀采样（邻接交换 MCMC）在
n=1.08M 下混合时间不可行，且与决策无关——三条独立证据（区域 CP-SAT、规范序
起点 SA、随机序 +32.5%）都不依赖均匀性假设。

## 6. 结论

**排序自由度相对规范序没有可利用的油水——区域与全图两个尺度、精确求解与随机
搜索两类方法证据一致。**

| 证据 | 尺度 | 方法 | 结果 |
|---|---|---|---|
| docs/08 §2 | 区域（≤216 节点） | CP-SAT 精确最优 | 规范序 gap 多数 0%，max 8.2% |
| docs/08 §3 | 512 区域（2k–8k） | SA 100k 迭代 | vs 规范序 median 0.0% |
| 本文 §3 | c910 全图（1.08M） | SA 32 链×2000 | **+0.0016%** |
| 本文 §4 | c910 全图 | 随机线性扩张 | 规范序比典型合法序好 32.5% |
| 本文 §5 | c910 全图 | 随机起点 SA 16 链×5000 | 爬不回规范序（多盆地/崎岖） |

对 Phase 2 的决策含义：

1. **GNN 学排序的前提不成立**：模型的全部价值在于"给出比规范序更好的序"，
   而规范序之上测不到 headroom（最好的可测上界 +0.0016%，区域证据 ≈0）。
   按 04 文档 R2 预案，应放弃模型路线。
2. **可交付成果是确定性流水线**：去 coarsen + 规范 Kahn + 新段 DP（带 λ=2–4
   段惩罚）——c910 cost −4.5%、dag_edges −30.5%、ccvp −23.1%；香山 cost
   −8.5%。零推理成本、零训练成本、确定性可复现。
3. **真正的剩余问题不是排序，而是粒度红线**：footprint +12~22%（128 硬容量
   vs 生产 coarsen 大块）是确定性路线也必须解决的 K9 体检矛盾（docs/08 §5
   已列选项）。NO0067/0086"大块更慢"的历史教训与 footprint 红线的权衡，是
   Phase 4 接回生产线前的核心工作。
4. 遗留尺度外推风险：c910 全图（1.08M 节点）与香山区域（≤8k）之外，香山
   全图（4.45M）未做 SA 实测；同工具同命令可直接跑（单次段 DP ~2s，
   32 链×2000 约 2h），作为结论的尺度稳健性确认项保留。
