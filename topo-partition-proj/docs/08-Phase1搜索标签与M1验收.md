# 08 Phase 1 搜索标签与 M1 验收

2026-07-30。Phase 1 四项任务（搜索器完整版、标签流水线、CP-SAT 量 gap、对照锚点）
落地，外加两个计划外但决定性的实验（全图 no-coarsen 基线、段惩罚权衡）。本文是
as-built 记录与 M1 验收门核对。**核心发现：规范拓扑序 + 新段 DP 在区域层面已接近
精确最优，相对生产基线的收益主要来自"去 coarsen + 新 cost 公式"，而不是排序本身。**

## 1. 搜索器完整版（任务 1，D7）

- **C 段 DP 内核**（`harness/kernel.c` + `kernel.py` ctypes 桥）：与 Python 参考 DP
  逐点对拍一致（20 组随机问题 × 5 排列）；n=5k 时单次约 40µs，比 Python 快约
  1000×——100k 迭代/区域从"不可能"变为 ~2 分钟。无编译器时自动回退 Python DP。
  内核支持段惩罚参数（见 §5）。踩过的坑：编译产物命名不能与被包装的模块同名
  （`.so` 导入优先级高于 `.py`）；stamp 数组跨调用复用必须严格递增。
- **移动合法性**：relocate 在"前驱之后、后继之前"的合法范围内均匀采样（对线性扩张
  是精确判定），swap 全检。Phase 0 的"随机位置 relocate"实测 97% 提案非法，是
  当时搜索全平的直接原因。
- **温度标定**（`calibrate_temperatures`）：从初始序采样合法移动的代价分布，
  t0 = 2×正 delta 均值、t1 = t0/100。固定 t0=10 相对整数代价地貌过热（accept-worse
  ≈90%，退化成随机游走），标定后各区域自适配。
- halo 冻结、只排内部非 commit 节点（state_write 读免费、不产值，与生产口径一致）。

## 2. 对照锚点与 CP-SAT gap（任务 3、4）

两个锚点（D5）：**生产锚点** = 生产 block assignment 限制到区域内、按搜索同口径
重算（`region_assignment_cost`，外部产生的划分与搜索结果公平可比）；**简化锚点**
= 规范拓扑序 + 段 DP（即搜索初始态、去 coarsen 版现有算法）。

**CP-SAT 精确最优**（`cpsat_oracle.py`）：monotone-seg 建模（边约束 seg[u]≤seg[v]
保证商图无环，由 02 §4 定理与"排序+段 DP"问题同最优；段容量 128；目标与段 DP
同口径）。12 个小区域（permutable 129–216）全部秒级证最优：

```
canonical vs optimal：0%–8.2%（多数为 0）
SA(50k) vs optimal：  median 0.00%，max 6.85%，67% 命中精确最优（cpsat_gap.json）
```

**结论 1**：小区域上规范拓扑序已经贴近精确最优（通常 ≤5% 内），SA 把残余 gap
基本补齐——M1 的"离最优 ≤5% 为佳"达成。**结论 2**：排序自由度在区域层面
（冻结边界下）的油水本来就只有几个百分点；规范 Kahn 序已经拿到了绝大部分。

大区域（2k–8k）上 SA 对规范序改善 ≈0（100k 迭代）：小区域经验（SA≈最优）与
"规范序贴近最优"两条证据共同指向大区域上标签 ≈ 规范序 ± 小幅扰动。这与风险
登记 R1 一致：区域层面对排序的约束有限，排序的全局价值要在全图层面验证
（见 §4 与 §6 后续动作）。

## 3. 标签流水线与 M1 汇总（任务 2）

目标规模 512 区域 × 100k 迭代（D7 上限）。产物
`exp/dataset/labels_xs_full_20260730/`（label_XXXX.npz：最优排列（全局 id 序）+
三口径分数；manifest.json：逐区域与汇总）。D7：标签只存最终排列，切点由 DP 重放。
流水线支持断点续跑（跳过已落盘区域），默认 8 workers（共享机纪律）。

**完整结果（512/512 区域，迁移后在外机断点续跑完成，32 workers、全程约 80 分钟）：**

| 对比 | median | mean | p25 | p75 | 改善面 |
|---|---|---|---|---|---|
| 搜索 vs 生产锚点 | **20.7%** | 22.0% | 9.1% | 32.7% | 96.9% 区域改善 |
| 搜索 vs 规范序 | 0.0% | 0.35% | 0.0% | 0.0% | 8.4% 区域改善 |

与 §2 的 CP-SAT 证据一致：大区域上标签 ≈ 规范序 + 小幅扰动，相对生产的收益
由"去 coarsen + 新公式"贡献。个别区域（min −23.4%）搜索劣于生产锚点——区域
限制语义下生产块跨界产生的非对称案例，留档不追查。逐区域数据与汇总见
`exp/dataset/labels_xs_full_20260730/manifest.json`。

## 4. 计划外实验 A：全图 no-coarsen 基线（D5 第二对照的全图版）

动机：若区域标签 ≈ 规范序，Phase 2 的 GNN 到底要打败谁？答案候选 = 全图
"去 coarsen + 规范 Kahn + 新段 DP"。`run_fullgraph_plaindp.py`：4,450,505 条
非 commit 指令，段 DP（C 内核）4.2s，commit 侧沿用生产块对齐口径：

| 指标 | 生产 plain | no-coarsen 规范序+DP | Δ |
|---|---|---|---|
| cost | 6,468,546 | 5,921,453 | **−8.5%** |
| dag_edges | 325,838 | 312,938 | −4.0% |
| ccvp | 3,305,393 | 2,903,510 | −12.2% |
| footprint（块数） | 34,236 | 41,637 | **+21.6%** |

**结论 3**：不动任何"学习"，仅去 coarsen + 新 cost 公式 + 确定性序，全图 cost
就降 8.5%——这是 K2 决策的直接定量验证，也是 Phase 2+ 必须超越的真基线。
**结论 4**：footprint +21.6% 越过 K9"体检指标不劣于基线"的红线——去 coarsen
严格按 128 切段（41,140 compute 块 vs 生产 33,738），块数增多。NO0067/0086
"大块更慢"与 footprint 红线形成真矛盾，需要权衡（见 §5）。

## 5. 计划外实验 B：段惩罚 λ 的 cost–footprint 权衡

段 DP 目标加段惩罚 λ（生产旧公式为 1.0；harness 评分公式本身不含），全图扫描：

| λ | cost Δ | dag_edges Δ | ccvp Δ | footprint Δ |
|---|---|---|---|---|
| 0 | −8.5% | −4.0% | −12.2% | +21.6% |
| 1 | −8.4% | −6.9% | −12.1% | +18.6% |
| 2 | −8.4% | −7.2% | −12.1% | +16.6% |
| 4 | −8.4% | −7.8% | −12.0% | +13.5% |

λ=2–4 是甜点：cost 几乎不动（−8.4%），dag_edges 进一步降到 −7~−8%，footprint
回落到 +13~17%。footprint 的剩余抬升源于 128 硬容量本身（生产经 coarsen 实际
块更大），λ 消不掉。**D3 细化建议**：段 DP 推理带 λ≈2–4 的段惩罚；footprint
红线如何与粒度红线共存（放宽容量 vs 接受 footprint 抬升 vs 更聪明的块合并），
留给 Phase 4 接回生产线前决策，需要先弄清 footprint 近似（块数）与真实代码
体积的关系。

## 7. 对 Phase 2 的输入

1. 标签已落盘（§3）：每区域 = 最优排列 + 生产/规范/搜索三口径分数。
2. **真基线更新**：Phase 2 的硬指标"不差于现有算法"应读作"不差于全图
   no-coarsen 基线（cost −8.5%、带 λ=2–4 段惩罚的版本）"，而非生产 plain——
   否则 GNN 学成后只是把确定性的东西重新学一遍。
3. **排序学习的天花板预警**：区域证据表明确定性序已接近局部最优；GNN 的
   潜在增量只可能来自区域边界冻结之外的全局结构（R1）。Phase 2 评估必须
   包含全图 cost（推理 → Kahn 修正 → 段 DP → harness scorer），不能只看
   区域 Kendall τ。
4. Phase 2 特征管线可以直接用 harness 的缓存图与区域文件；训练/评估都要
   报告 §4 的三个全图指标与 footprint。
