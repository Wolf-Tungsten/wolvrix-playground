# NO0146: NO0137 同源 `-O2` model build

> 从 `NO0093_essent_mffc_activity_schedule_plan_20260518.md` 拆出的独立实验记录，避免继续把多轮实验追加成单个长文档。


背景：

- NO0145 显示当前好档位 NO0137 的瓶颈偏向 generated code frontend / iTLB / branch 压力。
- 本轮复制 NO0137 同源 emit 产物，仅把 grhsim model 编译参数从 `-O3` 改为 `-O2`，验证较低优化等级是否减少代码膨胀并改善 runtime。

命令摘要：

```bash
cp -a tmp/no0137_xs_gated_mux_and tmp/no0146_no0137_o2_model
/usr/bin/time -p make -B -C tmp/no0146_no0137_o2_model/grhsim_emit -j32 CXX=clang++ CXXFLAGS='-std=c++20 -O2'
/usr/bin/time -p make -C testcase/xiangshan/difftest grhsim-build-emu GSIM=1 \
  DESIGN_DIR=/home/gaoruihao/wksp/wolvrix-playground/tmp/no0146_no0137_o2_model \
  BUILD_DIR=/home/gaoruihao/wksp/wolvrix-playground/tmp/no0146_no0137_o2_model/build \
  GEN_CSRC_DIR=/home/gaoruihao/wksp/wolvrix-playground/testcase/xiangshan/build/generated-src \
  SIM_TOP=SimTop \
  GRHSIM_MODEL_DIR=/home/gaoruihao/wksp/wolvrix-playground/tmp/no0146_no0137_o2_model/grhsim_emit \
  NOOP_HOME=/home/gaoruihao/wksp/wolvrix-playground/testcase/xiangshan \
  WITH_CHISELDB=0 WITH_CONSTANTIN=0 WITH_DRAMSIM3=1 \
  DRAMSIM3_HOME=/home/gaoruihao/wksp/gsim-playground/DRAMsim3 \
  EMU_TRACE=fst EMU_THREADS=1 NUM_CORES=1 WOLVRIX_GRHSIM_WAVEFORM=0 -j32
```

结果：

- model archive 强制重编：
  - `real 254.89s`
  - `user 5715.49s`
  - `sys 62.32s`
- difftest emu relink：
  - `real 1.21s`
- CoreMark 20k：
  - 10k: `host_ms=23333`
  - 20k: `host_ms=98681`
  - `Host time spent=98687ms`
  - 退出码 `0`，未出现 difftest mismatch。
- CoreMark 50k：
  - 10k: `host_ms=23504`
  - 20k: `host_ms=99133`
  - 30k: `host_ms=177856`
  - 40k: `host_ms=258553`
  - 50k: `host_ms=350963`
  - `Host time spent=350976ms`
  - 约 `142.46 cycles/s`
  - 退出码 `0`，未出现 difftest mismatch。

对比：

- NO0137 `-O3`：
  - 20k: `97854ms`；NO0145 perf 复测为 `99334ms`
  - 50k: `346589ms`，约 `144.3 cycles/s`
- NO0146 `-O2`：
  - 20k: `98687ms`
  - 50k: `350976ms`，约 `142.46 cycles/s`

判断：

- `-O2` 正确性通过，build 时间略低于 `-O3` 档，但 runtime 没有正收益。
- 50k 比 NO0137 慢约 `4387ms`，约 `1.27%` 负向；不应把 `-O2` 作为默认模型编译策略。
- frontend 压力判断仍成立，但单纯降低优化等级不能解决；下一步需要减少 generated code footprint / branch 数量本身，而不是依赖编译器优化等级。
