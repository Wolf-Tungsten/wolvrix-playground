## 3. Actual eligibility and frontier

emitter 输出：

```text
reads                  75,830
canonical              40,108
aliases                35,722
canonical groups       40,108
state/source groups    40,108
removed source heads   37,672
consumer heads         39,602
```

`75,830 = 40,108 + 35,722` 精确命中 NO0353 的严格 SimTop 上界，说明所有预期 canonical/alias groups 均通过
真实 emitter 的 protected、single-writer、user/fanout 和 local-user 检查。`removed source heads` 小于 group 数是因为
同一 state/source 中仍有 residual read 时必须保留 source；consumer heads 是按 state 去重后的 activation frontier 项。

被 direct marker 取代，而不是删除 IR/schedule 身份。

## 5. Hot mixed-supernode check

NO0353 定位的 `grhsim_SimTop_sched_8.cpp` supernode 7804 保持 108 个 ops，其中 106 个 register reads：

| Metric | NO0300 | Direct |
| --- | ---: | ---: |
| block lines | 542 | 230 |
| register reads | 106 | 106 |
| direct reads | 0 | 104 |
| `grhsim_changed_` references | 158 | 2 |
| same-state alias ORs | 52 | 0 |
| `kDiv` | 1 | 1 |

`logEndpoint$...NSamples` 和 `...Sum` 各有一条 boundary clone 被直连，另各一条 same-supernode local read 保留；尾部
`kDiv` 仍直接引用这两个 state storage offset，并保留自身 changed propagation。也就是说，高频 `timer`/histogram
扫描层被移除，而 NO0354 要求保留的 local calculation 没有被绕过。
