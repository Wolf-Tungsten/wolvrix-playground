## 实际实现

1. 普通 simplify/CSE 先自由执行；源码 node attrs 不进入功能键或重写准入。
2. nonsink node 构建读取当前 members。Bundle fieldPath 归并到源家族，
   instancePath 仍区分实例；Vector/数组保留 shape。没有 root 也可采用提示。
3. 相同源家族集合归入同一执行 node；多个家族共享的 ops 单独形成唯一
   shared node。shared-nodes 是 firrtl-nodes 的子集，不额外重复计数。
   不传递 union 相交集合、不恢复被 CSE 删除的运算、不复制以重建源码。
4. 临时 quotient 含真实 ValueId 依赖和 effect-order 边。用迭代 SCC
   分析定位环；只将环中多 op 的提示组退回 MFFC，其他提示不受影响。
   状态读和 effects 是真实边界 node，不因同名提示被吸收。
5. 其余 pure ops 逆拓扑构建 MFFC：全部真实消费者已在同一无提示锥时
   才吸收。锥内重汇合 fanout 可吸收；锥外 fanout、输出、提示及状态/
   效果是边界。没有 op 数、位宽 work 或 source-size 截断。
6. 上层 coarsen/segment 仅接收 Node DAG，不接收 Graph 或 op work。
   每 node 容量权重为 1，max-supernode-nodes 控制 SN 容量；分组后不
   fuse node 身份。legacy/bytes 只在边界代价上有差异，已移除 firing×work。
7. 可选 clone 进入已有目的 node，单独遵守 clone count/fanout 与输入
   已可用条件；不因增加 op 改变 node 容量。正例通过多周期 oracle。

默认 auto/legacy/128 nodes，直接落实“有提示按提示，无提示按 MFFC”。
显式 off 全部按 MFFC，供消融使用；该默认选择不代表已经证明性能提升。

配置升级为：

~~~text
v3/maxSupernodeNodes/segmentPenalty/semanticNodes/cloneShared/cloneMaxFanout/maxClones/cloneLossyCompare/firrtlNodes/costModel/hint-mffc-v1
~~~

C++ factory、Python FlowOptions、XS/reemit CLI、Make 和 inspector 已迁移。
旧 max-node-work、max-supernode-work、fuse-leaves 及对应环境变量明确拒绝；
v2/旧八字段完成态要求从 nonsink-sink-split 重新分图，不折算旧阈值。
源属性 schema 2 / soft-node-v2 不变。
