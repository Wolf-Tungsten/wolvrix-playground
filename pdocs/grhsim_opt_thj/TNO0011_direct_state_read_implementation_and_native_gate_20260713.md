# TNO0011 Direct state-read implementation and native gate

记录日期：2026-07-13

来源范围：`NO0350..NO0367`，原始记录见 [NO0350](../grhsim_opt/NO0350_state_read_boundary_locality_diagnostic_plan_20260712.md) 至 [NO0367](../grhsim_opt/NO0367_direct_state_read_full_empty_profile_gate_20260712.md)。

状态：single-writer scalar state-read direct forwarding 已实现且通过功能门禁；native layout 下删指令却回退，转入同址控制。

## 1. Locality diagnosis

默认关闭的 state-read locality TSV 将 register/latch read 的 source supernode、batch、alias、fanout 与 50k fire 连接。SimTop 结果：

```text
canonical dynamic visits in mixed supernodes  85.80%
single-writer direct candidate coverage        93.70%
batch8 coverage                               99.97%
```

GSim 在 writer 处直接激活 consumers，GrhSIM 则经 read slot changed scan 再转发；这是明确的二级中转层。

## 2. 实现

默认关闭的 direct forwarding 以 alias group 为整体判断：

- single-writer scalar register/latch；
- consumer 直接引用 state storage；
- commit frontier 改为 residual read heads + direct consumers；
- protected/local/multi-writer/wide/unsupported 保守保留；
- changed/no-change 与 alias fanout synthetic harness 闭合。

fresh SimTop 命中：

```text
direct reads  75,830 = 40,108 canonical + 35,722 aliases
generated bytes  -1.501%
generated lines  -1.629%
emu text          -1.132%
```

热点 SN7804 的 104 个 boundary reads 全部直连，changed refs `158 -> 2`、alias OR `52 -> 0`。

## 3. 功能闭环

标准 O3 build 后依次通过：

- 100-cycle reset smoke；
- 10k CoreMark/NEMU difftest 与 10 个 checkpoint；
- 50k、73,580 instructions 与 5 个 checkpoint；
- terminal PC `0x80001312`；
- mismatch/assert/abort/`input_fullpass_blocked` 扫描为 0。

## 4. Native runtime 反常

fixed-ASLR native A/B/A baseline cycles spread `0.515%`：

```text
instructions          -3.466%
backend stall density -11.567%
cmask6 density         +5.839%
cycles                +6.263%
```

cmask6 profile 中 direct full-empty samples `+12.949%`，compute 占增量 86.749%，但 top-10 仅覆盖 33.745%，没有单 IP 热点；110 个函数体和 116 个入口同时改变。

## 5. 阶段结论

direct forwarding 确实删除大量 state-read 指令且功能正确；native 回退与机制本身不一致，最可能是大函数地址/layout 漂移。开关保持默认关闭，下一步通过 4 KiB 和 exact-entry 实验隔离布局。

## 6. 规则审计与关键数据

记录类型：single-writer direct state-read 的实现与首轮 native root-cause 总结。单一议题边界是“删除 read-slot 中转层后，功能是否保持且 native binary 是否直接受益”。layout-controlled 因果结论属于下一阶段，见 [TNO0012](./TNO0012_direct_state_read_layout_control_and_final_profile_20260713.md)。

### 6.1 功能与结构 gate

- fresh emitter 命中 `75,830 = 40,108 canonical + 35,722 alias` reads；generated bytes/lines 下降 `1.501%/1.629%`。
- 100-cycle smoke 为 guest/model/cycleCnt/instr=`101/100/96/0`。
- 10k 为 guest/cycleCnt/instr/PC=`10001/9996/458/0x800027c6`。
- 50k 为 `50001/49996/73580/0x80001312`，五个 checkpoints 与 baseline byte-exact，且没有 `input_fullpass_blocked`。
