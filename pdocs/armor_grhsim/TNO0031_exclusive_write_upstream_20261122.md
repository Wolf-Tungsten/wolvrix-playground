从调度后图的 7,768,578 个操作逆向传播消费者归属。只要有通路到其他写口、掩码、事件、可观察副作用或顶层输出，该值就不计入目标写口的专属计算。60,900 个写口以完整操作符号和目标寄存器符号关联。把五个顶层输出、七个有返回值的 DPI 调用及其十一个结果显式标为外部可观察后，两个负载的逐组结果与原统计完全相同。[归属、覆盖与汇总脚本](./data/TNO0031_upstream_repro.tar.gz)

动态计数取 TNO0027 的发射模型及其站点清单，按 TNO0028 的两份访问序列分别计数。分母均为实跑的 100,001 拍。多个组共同消费的值只计一次，平均分给这些组。超过 64 组的共享值计入全图总和，分别有 271 / 233 次求值每拍未分到单组。总和还包含两类 reset 拒绝。按已分到组的次数，前 200 组占 93.1% / 91.3%。按全部专属求值则为 92.4% / 90.4%。[原站点记录](./TNO0027_xiangshan_change_site_pgo.md) · [两种负载的访问序列](./TNO0028_xiangshan_value_paths.md)

ROB 与 FTQ 合计每拍 26,490 / 19,718 次专属求值。ROB 原型的六个组是 7.9 / 6.0 次端口访问对 5,081 / 4,016 次上游求值。FTQ 的 64 个 `cfiAttr` 组是 30.3 / 22.2 对 6,487 / 4,058。三个访问最频繁的 `mux_chain` 组是共用使能的 DiffTest 寄存器排，CoreMark 合计约 501 次访问/拍，专属上游求值为零。CoreMark 的覆盖还记录了每拍约 1,098 次包围写口的条件检查，按类内分片及行号去重。[写口活动口径](./TNO0030_reg_to_mem_write_activity_20261122.md) · [ROB 原型的指令测量](./TNO0029_xiangshan_rob_indexed_writeback_20261122.md)
