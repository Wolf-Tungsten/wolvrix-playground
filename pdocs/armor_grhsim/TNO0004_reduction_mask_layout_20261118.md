# TNO0004：共享归约掩码的位号重排与八字节读取

**结论为局部压缩成立，整机收益未确认。** XiangShan 八对的候选相对基线外部 walltime 均值为 +2.12%，95% 配对 bootstrap 区间为 [−1.46%, +7.47%]。CV32 零命中，关键 ELF 节相同。实验模式保持默认关闭。[逐对数据与放置](../../build/armor-mask-read-v1/measurement/paired-walltime.csv)

本轮在 CV32 系列 TNO0049 的 shared-arm、紧凑快照配置上冻结同一份 XiangShan 和 CV32 输入，关闭上一轮的 `bool_lane_pack`。A 使用原有共享归约掩码，P 只变更私有位号和所有消费者常量，B 在 P 的相同位序上将完整的八个相邻 bool 槽合并读取。三个模式分别对应默认关闭的 `reduction_mask_layout=0/1/2`。在查看机器码前冻结了 B 对 A 的检验条件，P 只参与编译消融。[预先约定](./TNO0003_mask_input_direction_20261118.md) · [冻结规则](../../build/armor-mask-read-v1/frozen/policy.json) · [功能文档](../../wolvrix/docs/emit/grhsim-bool-reduction-masks.md)

## 生成与逐谓词核对

A 在当前 checkout 重新生成，XiangShan 140 个文件、CV32 21 个文件与 CV32 系列 TNO0049 基线逐字一致。XS 的 P/B 只改变 27 个 compute 翻译单元。独立程序从 A 的输入列表重算每个位的物理槽号与每个消费者的成员集合，并重建 P/B 的完整源码字节。689 个输入字、31,267 个谓词全部对齐。433 个输入字的八槽连续段增加，这些字有 20,208 个谓词，B 实际合并 543 个读块。在命中的 423 个 supernode 中，每个只发射一个无捕获的读取函数，两类输入字可共用它。27 个受影响翻译单元的 C++ 文本比 A 多 166,535 B；编译后的代码大小见下表。前期假设对所有字排序可见的 561 个块还包含收益未增加的输入字，生产规则只作用于上述 433 个字。CV32 全部三种输出相同，独立构建的 A/B ELF 的 `.text`、`.rodata`、`.data` 也逐节相同。[源码逐组审计](../../build/armor-mask-read-v1/frozen/source-audit.json) · [CV32 ELF 身份](../../build/armor-mask-read-v1/frozen/cv/B/sections.json)

两半的成员各自在原有的低／高 32 位范围内重排。稳定性、当前作用域、快照与输入数组的物理身份沿用现有证明，直接端口与不能证明的引用固定在原位。一个块恰好包含八个有效对象。B 在本次 node030 的 Clang 23.1.2 `-O3 -march=native` 下使用 BMI2 PEXT 提取字节低位，其他支持规范布尔字节的 x86-64 目标可用掩码乘法，其余布局有逐值路径。

## 功能验证

专项生成测试对长、短两类输入字运行独立参考，包括 AND、NAND、OR、NOR、直接端口与槽混用、63/64 个输入、跨 31/32 位、八种起始偏移和重复 eval。B 的实际读函数另用全部 256 种八位组合核对了本机提取及逐 bool 路径。O0/O3 ASan、UBSan 通过。最初的小模型只有一个消费者，槽分配本身已经遵循首次使用顺序，无法检验重排；最终 fixture 加入了独立的数值消费者来建立物理顺序。三项兼容 CTest、46 项 Python 回归也通过。[专项 CTest](../../build/armor-mask-read-v1/ctest-layout-final.log) · [兼容 CTest](../../build/armor-mask-read-v1/compat-ctest.log) · [脚本回归](../../build/armor-mask-read-v1/python-regressions.log)

XiangShan 的 A/B 均通过 10k smoke。两个 seed 各有 99,999 条完整 DiffTest 记录逐条一致，覆盖和结束签名通过。100k 窗口的终点为 PC `0x80000c1a`、250,838 条 guest 指令、100,001 个 guest cycles。计时样本另行预热，正式样本关闭 trace。[功能与覆盖](../../build/armor-mask-read-v1/measurement/xs/functional.json)
