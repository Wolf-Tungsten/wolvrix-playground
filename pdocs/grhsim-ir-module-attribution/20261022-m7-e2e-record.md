### 3.5 NNLS 数值失败与修复（实施期重要修正）

首跑 NNLS 完全退化：base[kind] 全 0、R²=-1385008、守恒违反 54%。两根因：
1. **行未归一**：rdtscp cycles 与 op 权重计数跨数量级，法方程被大超节点主导，projected-gradient/乘法更新压垮小超节点 → 全 0。修：`solve_nnls` 行归一（每行与其 target 同除以静态权重和，base 物理单位不变），R² 救回 0.4676。
2. **fallback 分子分母不一致**：base=0 的超节点分母用 static fallback 但分子 op_weight 仍乘 base=0 → cycles 凭空消失 → 守恒漏 54%。修：fallback 时分子分母同用 static（effective_base=1），守恒归 0。

### 3.1 探针 ODR 陷阱（已修复）

带探针 emu 首次运行在 `GrhSIM_SimTop::init()` SIGSEGV（任何 guest cycle 之前）。根因：M5 把 `snTimeCycles_[54032]`/`snTimeFires_[54032]` 两个 `std::array<uint64_t,54032>` 成员放在生成头 `#if WOLVRIX_GRHSIM_SN_TIMING` 下，**改变了生成类的二进制布局**；但 harness（grhsim csrc）经 `GRHSIM_CXXFLAGS` 编译时未定义该宏（difftest `grhsim.mk` 只对模型库传 `GRHSIM_MODEL_CXXFLAGS`），模型库与 harness 类大小不一致 → init 访问错位成员崩溃。**教训：改变生成类布局的编译期开关必须在所有包含生成头的 TU 间保持一致**（模型库 + harness + TB）。修复：`grhsim.mk` 的 `GRHSIM_CXXFLAGS` 增加 `-DWOLVRIX_GRHSIM_SN_TIMING=$(WOLVRIX_GRHSIM_SN_TIMING)`（并 `?= 0` 兜底），与 PERF/WAVEFORM 同样处理。注：M5 的 ctest `supernodeTimingTest` 单 TU 编译、hdlbits TB 经 CXXFLAGS 透传，均未跨 TU 暴露此问题。

### 3.2 difftest harness 对象失效陷阱

首轮 ODR 修复（grhsim.mk 加宏）后重跑仍崩在同一地址，且 emu 二进制时间戳停留在旧构建。根因：`grhsim.mk` 的 harness 编译模板 `GRHSIM_CXX_TEMPLATE` 依赖 `$(THIS_MAKEFILE)`，但该变量在被 include 时指向主 Makefile 而非 grhsim.mk 自身，故**改 grhsim.mk 不触发 harness 对象(grhsim.o)重编**，emu 也未重链。处理：彻底清理 `emu/grhsim-compile` + 模型库对象后全量重编，确保 harness 按新宏编译。教训：改动 difftest mk 的编译宏后，须删 harness 对象强制重编，不能依赖 make 失效推导。


## 4. 开销与稳健性

- **探针档编译增量**：默认档 571 s vs 带探针档 577 s，**+6 s（+1.0%）**，15 min 约束两档满足。
- **运行时开销 A/B**（同 workload coremark-2-iteration，cycleCnt=296749，difftest on）：
  - 默认档（SN_TIMING=0）Host time **757.986 s**，instrCnt=663682（与带探针逐位一致 → 正确性）
  - 带探针档（SN_TIMING=1）Host time **885.737 s**
  - **探针运行时开销 +127.75 s = +16.9%**，**超过**计划 ≤3% 目标。根因（计划 R4 预判）：54032 个超节点中大量是仅数个原生 op 的微超节点，rdtscp 双读时戳（~20-30 cycle）相对其成本不可忽略；fires 累计口径放大了每调用固定开销。
  - **含义与对策**：本口径下绝对周期数有 ~17% 系统性抬高，但**模块间相对归因（排名/占比）几乎不受影响**（开销近似均匀分布于所有超节点，三视图 tau=0.997 已证稳健）。若需更纯净口径：采样式探针（每 N 次触发计时一次）或粗粒度 chunk 计时（v2）。当前 v1 归因结论在相对口径下可用。
- **NNLS R²=0.4676**（kind×width 模型解释力有限，计划 §6.2 物理局限，已降级标注）；**守恒 0.000000%**；**Kendall tau=0.9969**。
