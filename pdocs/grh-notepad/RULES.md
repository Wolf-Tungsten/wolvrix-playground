# grh-notepad 文档管理规则

本文是 `pdocs/grh-notepad` 的独立规则说明文档，用于约束本目录后续的增量记录方式。
范式沿用 `pdocs/grhsim_opt/RULES.md`，差异在于本目录按**专题子目录**组织。

## 1. 适用范围

- 本目录按专题（topic）划分子目录，每个专题子目录承载一条线性的、带索引的研究记录链。
- 记录类文档统一采用增量归档方式管理。
- 管理类文档仅包含各级 `README.md` 与本 `RULES.md`，不占用记录编号。

## 2. 专题组织

- 一个研究专题对应一个子目录，目录名用简短 ASCII（如 `ir-scale`）。
- 新专题开新子目录，并同步在 `pdocs/grh-notepad/README.md` 的专题索引中登记一行（专题名、主题一句话、开题日期）。
- 专题子目录内必须有 `README.md` 作为该专题的线性记录索引。

## 3. 编号与命名规则

- 记录类文档文件名统一采用 `NOxxxx_主题_YYYYMMDD.md`。
- `NOxxxx` 为四位数字，**按专题子目录独立编号**，每个专题从 `NO0001` 起按记录形成时间单调递增，编号一经分配不得复用。
- 同一专题同一天新增多篇时，按形成先后继续递增。
- 新文档从该专题目录已分配的最大 `NOxxxx` 的下一个编号继续。

## 4. 增量记录规则

- 只追加、不覆盖：已有文档允许扩展，但只能追加新章节、补充说明、勘误或增量更新记录。
- 不允许删除历史结论、整体替换旧内容、复用旧文件承载新的独立主题。
- 新议题优先新建一篇 `NOxxxx` 文档，而不是覆盖旧文档。
- 修正错误时保留原结论上下文，以"勘误"或"增量更新 YYYY-MM-DD"形式追加。

## 5. 链接与引用规则

- 目录内引用统一用相对路径（如 `./NO0002_xxx_20260731.md`）；跨目录引用也用相对路径（如 `../../../topo-partition-proj/docs/26-....md`）。
- 不用仓库绝对路径或机器本地绝对路径作为 Markdown 链接目标；命令示例、产物路径可保留绝对路径文本，但不写成 Markdown 链接。
- 迁移进来的历史文档正文中保留的"doc NN"式文字引用，以该专题 `README.md` 索引中的**原编号映射列**为准，不回改正文。

## 6. 迁移规则

- 从其他目录迁入的基础记录按原时间顺序重新分配本专题编号，迁入后在专题索引中登记原路径/原编号映射。
- 源目录的索引（如 `topo-partition-proj/README.md`）同步更新：移除迁出行，留下指向新位置的说明。
- 迁移只移动文件、更新索引，不改正文内容。

## 7. 目录维护要求

- 每次新增记录后，必须同步更新该专题 `README.md` 的索引（编号、标题、日期、一句话内容）。
- 每次新增交叉引用后，检查链接仍为相对路径。
