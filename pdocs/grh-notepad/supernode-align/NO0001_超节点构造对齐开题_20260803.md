# NO0001 超节点构造对齐开题

日期：2026-08-03
前置专题：[../ir-scale/](../ir-scale/README.md)（AM vs gsim 打平图 op 数对齐，香山收官 1.0042x）

## 1. 背景与目标

ir-scale 专题已基本对齐 AM 图与 gsim 打平图的 op（node）数量。本专题进入下一阶段：**对齐两者的超节点构造算法**。

- gsim 侧：supernode 由 gsim 自身 coarsen 流程产出（参考实现 `reference/gsim`，只读）。
- AM 侧：超节点 = grhsim AM 的 **compute block**，由 `wolvrix/lib/grhsim/am/activity_schedule.cpp` 的 coarsen-dp 块构造产出。

**对齐指标**：在同等超节点数量前提下（AM compute block 数对齐 gsim supernode 数），AM **跨超节点的 value 数 ≤ gsim 的 110%**。

## 2. 指标口径（草案，首篇实测记录中固化）

- 超节点数量：gsim supernode 总数 vs AM compute block 总数；AM 侧通过 coarsen budget 等手段对齐到与 gsim 相同（或更少）的数量后再比 value。
- 跨超节点 value：def 与 use 分属不同超节点的 value 数（两侧各自按本侧超节点划分统计，取去重后的 value 数）。
- 基准设计：XiangShan（香山），与 ir-scale 专题同一基准；c910 可作为旁证。
- 正确性门控：香山 AM 全流水 + 50k difftest 通过（沿用 ir-scale 的门控方式）；**不做仿真性能门控**，一切以压边数为努力方向。

## 3. 现状

- AM coarsen 当前为单 pass 内三规则轮询：`CoarsenPass::Out1` / `In1` / `Sibling`（`wolvrix/lib/grhsim/am/activity_schedule.cpp`），带 coarsenBudget 上限、tail 小步退出（连续 3 轮 cluster 增量 < 1024 且 cluster 数 ≥ 100000 时停）与 256 轮硬上限。
- gsim 侧 supernode 构造在 `reference/gsim`（只读参考），历史对比记录见 `pdocs/grhsim_opt/`（legacy grhsim 时代，口径仅作参考）。
- 基线数据（两侧超节点数、跨块 value 数）**尚未测量**，是第一篇实测记录的任务。

## 4. 路线

1. 建测量：可重复运行的对比脚本，输出两侧超节点数、跨超节点 value 数及比值；固化口径。
2. 归因：对 gsim 超节点做规则层面的构造分析，找出 AM 缺失的合并形态。
3. 扩展 coarsen 变形规则：不拘泥于单个 pass，可做成一组 pass 探索规则匹配；每加一条规则即重跑测量与 difftest 门控。
4. 迭代至指标达成，或在压不动时输出最佳结果 + 归因。

## 5. 边界

- 只改 AM 侧（`wolvrix/lib/grhsim/am/` 及必要的 pass 基础设施）；`reference/gsim` 只读。
- 不为仿真性能做折衷；性能回归暂不阻塞合入。
- 每篇记录按 [../RULES.md](../RULES.md) 递增编号并回本专题 README 索引。
