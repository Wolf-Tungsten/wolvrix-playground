# NO0013 atom 口径基线：节点单位对齐与新读数

日期：2026-08-08
前置：[NO0010](NO0010_归零重启打平图基线_20260804.md)（打平图基线）、[NO0012](NO0012_口径重构compute网络主指标_20260804.md)（compute-network 主指标）、am-graph [NO0006](../am-graph/NO0006_同条件mux原子化与if-else发射_20260807.md)/[NO0007](../am-graph/NO0007_atom一等公民化与对齐口径重构_20260807.md)。

## 1. 口径问题的证实（2026-08-07 核实）

NO0010 的 gsim"打平图"并不打平 when：`reference/gsim/src/flattenNodes.cpp` 明确豁免 OP_WHEN（"conditional-assignment skeleton, control, not compute"），嵌套 when 骨架整棵留在 owner 节点内；导出按树根 opType 计——一棵骨架 = 1 条 OP_WHEN 指令。量化（`xs_gsim_flat_prod_20260804`）：OP_WHEN 根 126,005 条、打平日志 `keptWhen 87,356`（折叠隐藏的嵌套 mux 决策，平均 1.69/根）。对照 AM 侧 468,709 个 mux 当时全部展开为独立指令。两侧"节点"粒度不同：gsim node = 1 compute enode + 任意大小控制骨架，AM instruction = 单算子全展开。

## 2. 用户判断（2026-08-07，原文要点）

1. gsim 统计口径不动：compute node 算一个 node，flatten 不打平 when。
2. AM 保持图结构 + block 内 atom 层次到发射端（atom 上附加 SCC 收敛、mux 合并、commit cond 聚合等信息）。
3. 分图算法与统计口径与 gsim 看齐：**atom 就是原子**——分区大小的单位、边结构的基础。

## 3. 落地：atom 一等公民化（am-graph NO0007）

- AM Program 增加 atom 层（block→atom→instruction；kind ∈ Singleton/MuxMerge/CombLoopScc/CommitEvent + 签名元数据），emitter 直消费 atom（删 planMuxRuns 双机制），分区经济模型全换 atom 计权（`maxAtomsPerBlock=128` 等）。
- 研究导出：指令图/块归属 JSONL 携带 post-merge atom id。
- 指标：`scripts/supernode_align_metrics.py` 按 atom-as-node 统计（atom 列缺失的旧数据/gsim 侧回退 instruction=node）。
- 验证：P1 发射产物字节级不变；P2/P3 香山 difftest 均 73,580/49,996 逐位一致；host P2 314.2s / P3 309.7s（canonical 312.8s，不回退）。详见 am-graph NO0007 §8-§9。

## 4. 新基线读数（2026-08-08，本口径取代 NO0010 表成为当前默认对比）

数据集：AM `topo-partition-proj/exp/dataset/xs_am_no0007p3_20260808/`（atom 计权分区，post-merge atom 口径）vs gsim `xs_gsim_flat_prod_20260804`（不变）。`scripts/supernode_align_metrics.py` 无参运行即本对比。

要点：

- **nodes 0.8608x**：atom 口径下 AM 节点数已低于 gsim（3,032,212 条指令中 412,087 条藏于多指令 atom 内，主要是 MuxMerge atom——与 gsim when 骨架折叠同构的折叠单元）。
- **主指标 2.8911x**：对比 NO0006 时代同分母读数 3.05x，atom 计权分区改善 −5.2%；距达标线 ≤1.10x 仍远，差距为结构性，归 supernode-align 后续专题（容量用足——AM 块均值 116 atom 尚未触及 128 上限的等效 gsim 分布、图形 pass 等）。
- **边口径证据**：两侧 `def_use_value_edges` 与各自原始 def_use 边数恒等（4,340,605 / 5,207,300），证明两侧导出本就同为 (dst,var) 去重口径，"边结构基础"无隐性水分；剩余 1.20x 是真实图密度差。
- **commit 块 481 个两侧口径一致排除**于主指标（compute-network 口径，NO0012）。
