# NO0003 归因：轮询调度扼杀 Out1 链式合并

日期：2026-08-03
前置：[NO0002](NO0002_基线测量与口径固化_20260803.md)（基线 8.095x）

## 1. 块数归一实验：差距与块数无关

AM 侧用 `--max-instructions-per-block` 扫块粒度（同一 post-stats、同一指令图）：

| 配置 | 超节点数 | cross_values |
|---|---:|---:|
| prod（max=128, budget=192） | 25,860 | 1,503,473 |
| max=48（budget=72 auto） | 65,820 | 1,545,877 |
| max=32（budget=48 auto） | 99,820 | 1,565,782 |
| gsim 参照 | 84,786 | 185,716 |

块数从 25.8k 涨到 99.8k（3.9×），cross_values 反而微涨 —— 跨块 value 对块粒度**不敏感**，差距是划分质量问题，不是块数预算问题。同粒度（~100k vs 84.8k）下比值 8.43x，比基线更差。

## 2. 块尺寸分布：gsim 有鲸鱼尾，AM 没有

| 桶（节点/块） | gsim 块数 | gsim 节点占比 | AM prod 块数 | AM 节点占比 |
|---|---:|---:|---:|---:|
| 5-15 | 57,393 | 26.2% | 631 | 0.1% |
| 65-128 | 1,562 | 5.1% | 12,448 | 41.2% |
| 129-256 | 1,100 | 8.0% | 10,803 | 52.4% |
| >256 | 922 | **40.2%** | 45 | 4.2% |

gsim 的 922 个 >256 节点的超节点（最大 9,913）吞掉了 40% 的节点：鲸鱼内部定义了全图 44% 的 value（1,051,025 / 2,399,420），但外泄仅 14,510 个跨块 value。gsim 跨块 value 的 65% 是 small→small 块间、27% 是 small→whale。

## 3. budget 实验：coarsenBudget 不是约束

`--dp-coarsen-budget` 192 → 2048 / 7000（max=128 不变）：

| 配置 | 超节点数 | cross_values | clusters_after_coarsen |
|---|---:|---:|---:|
| budget=192 | 25,860 | 1,503,473 | 227,149 |
| budget=2048 | 9,837 | 1,484,285 | — |
| budget=7000 | 9,216 | 1,480,771 | 213,488 |

budget 放大 36 倍，cluster 数只少 6%，cross_values 几乎不动。合并确实发生了（b7000 的 out1_merges=1.42M 与 prod 持平），但**合并的不是跨块 value 的边**。budget 从来不是约束。

## 4. 跨块 value 的形态归因（prod 划分）

- 1,503,473 个跨块 value 中 **1,256,499（84%）只有单一消费块**。
- 其中 **957,829（76.2%）的生产者 atom 出度恰为 1**（def_use 口径；计入 order 边后仅 1 例变化，order 边不阻碍）。
- 即约 96 万个"纯链环节"（生产者 → 唯一消费者）被切在不同块。
- 这类合并被 budget 阻止了吗？看两侧块大小之和：>192 的占 97% —— 表面上是，但 §3 证明 budget 放大后这些链环依然不合并（b7000 下 single&outdeg1 仍有 942,666）。

## 5. 决定性实验：Out1 单独跑到 fixpoint 可以 100% 合并这些链环

在导出的 atom 图（def_use+order 边，commit atom 排除）上只跑 Out1 规则（batch 近似，budget=7000）：29 轮收敛，**2,388,902 个出度 1 的非 commit atom 与其唯一后继 100% 同簇**。

结论：链环切分不是图结构或 budget 造成的，是**生产调度的轮询（Out1→In1→Sibling 轮转）把出度 1 性破坏掉了**：In1 把有多余后继的前驱并入链中节点、Sibling 把同层兄弟并入，都会让目标 cluster 的出度从 1 变成 ≥2，此后 Out1 永远无法再合并这条链（Out1 只看出度==1 的 cluster）。

gsim 的对照（`reference/gsim/src/graphPartition.cpp:50-59` `graphCoarsen()`）：**顺序相位**，每个规则跑完再跑下一个——`mergeResetAll → mergeWhenNodes → mergeOut1 → mergeIn1 → mergeSublings`，不轮转。Out1 在 In1/Sublings 之前跑完，链先收拢，后续规则破坏不了已经完成的链合并。

## 6. 规则沙盒与首轮 A/B

为低成本 A/B 规则变形，写了生产 coarsen 的离线复刻：

- `topo-partition-proj/exp/harness/amcoarsen.py`：DSU + 每轮重建 cluster 图 + mergeMark + Out1/In1/Sibling 三规则 + rotate/sequential 两种调度 + 确定性 Kahn + 贪心容量打包（段 DP 的近似）。
- 驱动：`scripts/supernode_align_sandbox.py <instruction_graph.jsonl> [--mode ...] [--budget N] [--max-instructions N] [--max-iters N]`。

**对账（rotate, budget=192, max=128，对齐生产配置）**：

| 指标 | 沙盒 | 生产 | 偏差 |
|---|---:|---:|---:|
| Out1/In1/Sibling merges | 1,460,610 / 390,327 / 1,198,379 | 1,419,894 / 389,949 / 1,220,554 | ≤3% |

复刻可信（差异来源：贪心打包 vs 段 DP、tail-stop 未实现、个别排序细节）。

**A/B：sequential（gsim 相位序：Out1→In1→Sibling 各跑至收敛）vs rotate**（同图、budget=192、max=128）：

| 指标 | rotate（≈生产） | sequential | 变化 |
|---|---:|---:|---:|
| cross_values | 1,442,871 | **724,131** | **-49.8%** |
| dag_edges | 277,441 | 338,858 | +22% |
| compute blocks | 24,759 | 27,835 | +12% |
| Out1 merges | 1,460,610 | 2,385,656 | +63% |

相对 gsim 主指标比值：**8.10x → 3.90x**（块数 27,835 ≤ 84,786，约束仍满足）。Sibling 在 Out1/In1 收敛后找不到任何同层兄弟——AM 的 level-based sibling 规则被前两个相位完全覆盖。`sequential:0`（循环至稳定）与单周期结果完全一致，与 gsim 每规则只跑一遍一致。

注意：两轮实验 rounds 均打满 256 轮上限（Out1 相位被 mergeMark 限速：扇入星型簇每轮只能并进一个前驱），**Out1 未充分收敛，还有头room**（i8192 实验进行中）。

## 7. 生产落地：相位式调度（2026-08-03）

`wolvrix/lib/grhsim/am/activity_schedule.cpp` 调度循环从轮转改为相位式（Out1→In1→Sibling 各跑至 fixpoint；kMaxCoarsenIterations 256→1024；tail-stop 保留为全局安全闸）。

生产实测（同 post-stats、同调度参数，lower-json 重跑）：

| 指标 | rotate（基线） | sequential（生产） | 变化 |
|---|---:|---:|---:|
| clusters_after_coarsen | 227,149 | 904,491 | +298%（少合并≠差，见下） |
| out1/in1/sibling merges | 1,419,894 / 389,949 / 1,220,554 | 2,342,155 / 0 / 0 | — |
| compute blocks | 25,379 | 30,015 | +18% |
| **cross_values** | **1,503,473** | **744,513** | **-50.5%** |
| **vs gsim 比值** | **8.10x** | **4.01x** | — |
| dag_edges | 286,642 | 284,331 | -1% |
| coarsen_ms | 2,018 | 2,162 | +7% |

与沙盒预测（724,131）偏差 2.8%，沙盒可信。块数 30,496 ≤ 84,786 约束满足。

生产与沙盒的一个机制差异：生产 Out1 相位被 tail-stop 提前结束（扇入星型簇每轮只能并进一个前驱，delta <1024 三轮即停），所以 In1/Sibling 相位在生产没有活儿（0 merges）；沙盒无 tail-stop，In1 多收 237k、Sibling 多收 437k 但 cross_values 反而变差（795,265 vs 724,131，贪心打包噪声 + sibling 合并不内聚）。**结论：保留 tail-stop；Sibling 相位暂留观察（生产当前等价于纯 Out1+DP）。**

正确性门控：香山 AM 全流水 + 50k difftest **通过**（2026-08-03，build/xs/grhsim-am-seq）：`Core-0 instrCnt = 73,580, cycleCnt = 49,996`，与 b1 参考值逐位一致（EXIT 0）。环境注记：本机 zstd.h 缺失，emu 构建需 `NO_ZSTD_COMPRESSION=1`（详见 NO0004 §5）。
