## 3. 可达性终审

全部已量化杠杆（沙盒口径，基于 GOut1+GIn1 的 620,522）：

| 杠杆 | 效果 | 依据 |
|---|---:|---|
| 相位式调度（已上生产） | -50% | NO0003 |
| 放开 budget | -13% | NO0004 §3 |
| replication tier-2 | -17%（+26.5 万指令） | NO0004 §4 |
| alias 消除 | -3.6% | 本文 §1 |
| sibling/PrevSibling/MuxCond | ±3% 噪声 | NO0004/NO0005 |

**完成判据（≤1.10x）在目标给定范围内不可达**，证明：

1. commit 侧跨块 value 182,810（AM 单态 + commit 后缀的执行模型固有，gsim 双态 $NEXT 可并入生产者超节点）——单独即占 gsim 总量（185,716）的 98.4%。
2. 要满足总量 ≤ 204,288，compute→compute 需 ≤ 21,478，即在现有 566,792 上再削 96%；而即使把 AM 图收敛到与 gsim 完全相同的 fanout≥2 规模与吸收率（69%），总量也在 ~455k 量级。
3. 剩余图形级杠杆（slice 融合、logic_and 守卫重构、mem.read 去重）单项收益均为个位数百分比（alias 实测 -3.6% 为参照），组合上限远不足以翻转结论。

**最佳已达成绩：4.01x（生产，744,513 vs 185,716；块数 30,496 ≤ 84,786；香山 50k difftest 通过，73,580/49,996 与参考一致）。**

## 4. 建议的下一步（交用户决策）

1. **口径调整（推荐先评估）**：commit 侧跨块视为 AM 执行模型固有、不计入"超节点构造质量"。调整后口径为 compute→compute：当前 566,792 vs 171,021 = 3.31x，后续图形级 pass 在此口径下继续压。
2. **commit 架构吸收**：AM 引入 next-state 缓冲（commit 指令可与生产者同块），从根上消除 182,810；工作量大且涉及执行模型语义，需立项。
3. **继续图形级 pass**（无论口径如何都有价值）：alias 消除（-3.6%，且顺带降指令/边数）、slice 融合、logic_and 守卫重构、mem.read 端口复用。
4. replication 生产化（-17%，代价 +7% 指令数）——是否接受指令数膨胀由用户定（与 ir-scale 的 op 数成果存在张力）。
