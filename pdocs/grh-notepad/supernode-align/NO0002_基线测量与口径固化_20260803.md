# NO0002 超节点对齐基线测量与口径固化

日期：2026-08-03
前置：[NO0001](NO0001_超节点构造对齐开题_20260803.md)（开题）

## 1. 口径固化

- **数据源**：两侧统一走 topo-proj JSONL 导出（同一对格式 `wolvrix.am-instruction-graph.v1` / `wolvrix.am-block-assignment.v1`，同一 loader 消费）。
  - gsim 侧：`--export-topo-proj`，取 `block_assignment_dp.jsonl`（dp 阶段 = 最终发射的超节点划分）。
  - AM 侧：`WOLVRIX_GRHSIM_AM_INSTRUCTION_GRAPH_JSONL` + `WOLVRIX_GRHSIM_AM_BLOCK_ASSIGNMENT_JSONL` 环境变量，随 `grhsim-am-lower-json` 生产调度导出。
- **主指标 `cross_values`**：存在至少一条 def_use 边且 producer block ≠ consumer block 的去重 value 数（commit 类消费块计入）。
- **超节点数**：gsim = dp assignment 的 blocks；AM = compute_blocks + commit_blocks（input sink 不计；AM 导出无 entry 块记录）。
- **不计入主指标**：external_read（寄存器状态 / 接口输入 / 存储内容）。两侧同为"永久边界"，与划分质量无关，仅作上下文列报。
- **达标判据**：AM 超节点数 ≤ gsim 超节点数，且 AM `cross_values` ≤ gsim 的 110%。
- 备注：gsim `SimTop_supernode_stats.json` 的 supernodes=84,642 与 dp assignment blocks=84,786 差 144（0.17%，统计口径不同）；对齐比较统一用 dp assignment 数。

## 2. 复现命令

    --gsim-graph topo-partition-proj/exp/dataset/xs_gsim_prod_20260803/instruction_graph.jsonl \

### 勘误（2026-08-04）

本文 §3 的 instructions 比值 1.253 与 ir-scale 专题收官的 1.0042x **不是同一口径**，不能并列比较：

- 1.0042x 的分母是 gsim **打平图**（`--flatten-nodes`，3,043,902 节点），分子是 GRH 层 compute op（排除 source/sink/decl/hier/array 五类，2,825,239）。
- 本文 1.253 的分母是 gsim **生产图**（表达式树折叠，2,708,079 节点），分子是 AM 指令图全量指令（3,394,012，含 commit 写 147,366）。
- 本专题的对齐对象是 gsim 生产图（gsim 实际做超节点划分的图），1.253 是本专题的正确基线；对称剔除 commit/状态写后比值为 1.270（3,246,646 vs 2,556,889）。
- 另注：ir-scale 收官的 2,825,239 是收官时点测量值；当前 `build/xs/grhsim-am-b1/wolvrix_xs_post_stats.json` 已被后续不同配置的运行重写，该数字在该文件上不能直接复现。

## 4. 差距结构初判

1. **块数与质量混在一起**：AM 块数只有 gsim 的 30%（平均 131 指令/块 vs 32 节点/块），但跨块 value 反而 8 倍。块更大本应吞掉更多边，说明 AM 的划分在 value 局部性上远差于 gsim，不是块数差异能解释的。
2. **图本身有差异（非主因但需在归因中扣除）**：AM 指令数 1.25×、def_use 边 1.44×（ir-scale 对齐的是 compute op 数，寄存器/存储读写端口等使 AM 指令与边更多）。
3. **规则面差异（待逐条验证）**：
   - gsim coarsen 有 `mergeWhenNodes`（同 when 条件节点并入条件所在 supernode）与 `mergeResetAll`，AM 无对应物。
   - gsim `mergeOut1/In1` 允许 cluster 长到 `MAX_NODES_PER_SUPER=7000`；AM `coarsenBudget=192`（auto=1.5×128）硬顶 cluster 指令数。
   - gsim 的 dp 段内可装 15 个 cluster（段容量按 cluster 计），AM 段 DP 按指令数 ≤128 切。
4. **扫描序局部性**：AM 块是线性扫描序的连续段，序的局部性直接决定跨块 value；gsim coarsen 可以跨序合并（只保拓扑约束）。这大概率是最大差距来源，需要量化（如下调 AM 块大小到 gsim 粒度后 cross_values 涨多少、同一块数下重排能压多少）。

## 5. 下一步（按优先级）

1. **块数归一实验**：AM 调小 `--max-instructions-per-block` / `--dp-coarsen-budget` 使超节点数贴近 84,786，分离"块数预算"与"划分质量"两个因素，得到同粒度下的真实差距。
2. **规则归因**：统计 AM 跨块 value 的分布（按块、按值宽、按扫描序距离），对照 gsim merge 规则找出 AM 缺失的合并形态（候选：when 簇、reset 簇、长链 out1/in1）。
3. 此后进入"逐条加 coarsen 规则 → 重测 + difftest 门控"的主循环。
