# NO0002 细粒度截断归因与 DP 后局部移动精化

日期：2026-08-06
状态：已落地并验证（difftest 结果见 §7 补记）

## 1. 目标

修 NO0001 发现的头号问题：AM 分区器（coarsen + segment DP）在细粒度
（~88k 块，对标 gsim 生产划分粒度）失效——离线复刻在 88k 块 cross_values 爆到
1.13M（gsim 生产 178k 的 6.37x），生产分区器 cap=46 也在 76k 块拿到 604,843
（3.40x）。NO0001 判定的路径库存第一项就是"修 DP 容量截断"。

## 2. 归因坐实（修之前先测）

- **分区器 vs 图**：同一离线分区器、同等细粒度下，AM 图 1,134,926 vs gsim 图
  798,967——**图结构差 ~1.42x**；而 gsim 生产分区器在同一张 gsim 图上拿到
  178,151——**分区器在细粒度失效 ~4.5x**，是主因。
- **不是 oversized 单例**：两图细粒度重分区 oversized 块均为 0；截断信号是容量
  利用率（平均填充 ~73%）与出度-1 链被容量切碎。
- **爆发点分解**（cap=46，604,843）：出度=2 桶最大（246,897，结构性扇出，与
  NO0012 一致）；**出度=1 桶增长最猛**（157,648，对 gsim 6.23x、比 cap=128 生产
  再 +43%）——链被切碎是细粒度特有增量；hub 与宽值均非主因（top1000 仅占
  9% 对数；≥65 位 value 仅 1.42%，贡献 du 对级 copy cost 14.2%）。
- 生产 DP 优于离线复刻（cap=46：604,843 @ 76,358 块 vs 1,134,926 @ 88,118 块），
  但离 gsim 生产 178k 仍差 3.4x。

## 3. 修法：DP 后确定性局部移动精化

根因结构：segment DP 把**固定拓扑序列切成连续段**，无法按连通性跨序列距离归并
（gsim 的 graphPartition 是按连通性分组的另一算法族）。在 DP 之后加一轮
**局部移动精化**（`refineClusterBlocks`，grhsim_am_compute_graph_partition.cpp）：

- 按 cluster 拓扑序扫描，尝试把 cluster 移入 cluster DAG 邻接块；
- 仅当**精确的块级 incoming-copy 成本**（与生产记分牌 pairs 同口径：(value, 块)
  去重、永久边界每块都计、可选位宽加权）严格下降才移动——增量公式只涉及源/目
  两块（消费块不受影响），单调降本必然收敛（上限 `dpRefinementRounds`=10 轮）；
- 全确定性：固定扫描序、候选块升序、最优 delta + 低块号决胜；
- **拓扑硬约束**：移动候选必须满足 `max(前驱块) ≤ T ≤ min(后继块)`——保持
  DP 原有的跨块 def-before-use。无此约束的第一版把 changed 生产者挪到消费者
  之后（validator 直接拒绝），而且普通值的反向边会白加收敛轮；加约束后通过。
- 超大 cluster 不动（保持单例）、不清空块（块号稳定）。

|---|---|---:|---:|---:|
| cap=128（生产） | cross_values | 527,025 | **518,382** | −1.6%（比值 2.96x→2.91x） |
| cap=128 | value-block pairs | 1,913,302 | 1,861,491 | −2.7% |
| cap=128 | incoming_copy_cost | 5,008,284 | 4,954,973 | −1.1% |
| cap=128 | detectors / activation_edges / scheduled_instructions | 669,894 / 1,589,559 / 4,550,398 | 661,251 / 1,540,359 / 4,533,112 | −1.3% / −3.1% / −0.4% |

## 5. 诚实结论：截断是算法族的结构性问题

局部移动（KL 式邻接移动 + 拓扑约束）**只追回 1-3%**——容量墙（生产块平均填充
84%）与拓扑约束让大多数 cluster 无处可去。细粒度失效的本质是 DP 的
"拓扑序列连续切分"模型：它从原理上无法做连通性分组。要拿到 gsim 生产划分
（88k 块 @ 178k）级别的结果，需要**换成连通性导向的分区算法**（参考 gsim
graphPartition 的算法族），而不是在切分模型上调参。本轮的增量仍值得保留：
它是严格的降本改进，且减少了生产模型的 detector/激活边/调度指令开销。

- `refineClusterBlocks`（grhsim_am_compute_graph_partition.cpp）+ 输入开关

  `dpRefinementRounds`，默认 10，0 关闭）+ 结果统计字段（refinementRounds/

  DP 唯一次优 pairs=5 → 精化一次移动 pairs=4，块指派逐位断言，含 rounds=0 对照）。
- AM 套件 10/10。
