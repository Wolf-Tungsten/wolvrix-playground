# NO0004 流程框架与术语统一

日期：2026-08-06
状态：已完成并验收（三份产物字节级不变，AM 10/10）

## 1. 目标

用户裁定的标准流程框架（术语以此为准）：

```text
GRH IR
  -- lowering-to-am-graph     --> GRHSIM AM Graph
  -- opt-am-graph             --> GRHSIM AM Graph（整体优化后）
  -- split-am-graph           --> GRHSIM AM Compute Graph
                                + GRHSIM AM Commit Graph
  compute 线:
    -- opt-am-compute-graph   --> （当前为空，预留阶段）
    -- partition-am-compute-graph（活动度划分）
                              --> GRHSIM AM Compute Activity Graph
  commit 线:
    -- partition-am-commit-graph（事件聚类）
                              --> GRHSIM AM Commit Event Graph
  -- materialize              --> GRHSIM AM Program（AM Compute Activity Graph
                                  + AM Commit Event Graph 物化）
  -- emit                     --> C++ 模型
```

要求：代码与文档严格遵照该框架组织；当前为空的阶段（opt-am-compute-graph）也要
留下显式阶段边界。

## 2. 现状到框架的映射（改造前）

| 框架阶段 | 改造前对应 | 差距 |
|---|---|---|
| lowering-to-am-graph | `GrhToAmLowering::lower` → `AmGraph` | 已就位（NO0003） |
| opt-am-graph | `optimizeAmGraph`（fold/alias/memfold/cse 不动点 + DCE） | 已就位（NO0003） |
| split-am-graph | 调度器入口内联完成 def-use/SCC/atom 分类后 `splitGrhSimAmActivityGraph` | 阶段边界不显式；命名不带框架术语 |
| opt-am-compute-graph | 不存在 | 需新增空阶段 |

     （产物 `AmComputeActivityGraph`）/ `partitionAmCommitGraph`（产物

2. `production_activity_schedule.cpp` 的 `schedule()` 按框架重排为显式阶段：
   split（含 def-use/ordered/SCC/atom 分类/事件签名规范化）→ opt-am-compute-graph
   （空调用）→ partition-am-compute-graph → partition-am-commit-graph → materialize
   （合并全局编号 + input sink + 门控/激活/finalize 物化 AM Program）。
3. 文档：`grhsim-am-pipeline.md` 的流程图与 2.4/3.2 节改按框架术语；术语表落到
   NO0004 本文档。
4. 验证：香山指令图 / block assignment / C++ 发射三份产物字节级不变；AM 套件 10/10。

## 4. 术语约定

- **GRHSIM AM Graph**：lowering 产出、opt-am-graph 消费的全量图（compute+commit
  指令同在，var 带 Comb/Constant/Input/State 分类与 PreCommit/Live 边语义）。
- **GRHSIM AM Compute Graph / Commit Graph**：split-am-graph 产出的两张 atom 级
  诱导子图；跨类边（compute→commit）不属于任一子图，commit→compute 边非法。
- **GRHSIM AM Compute Activity Graph**：compute 图 + 活动度划分结果（atom→block、
  块内拓扑）。
- **GRHSIM AM Commit Event Graph**：commit 图 + 事件聚类划分结果。
- **GRHSIM AM Program**：materialize 物化的线性最终程序（`ScheduledProgram`，
  含块布局、门控 detector、`act.f/act.b`）。
