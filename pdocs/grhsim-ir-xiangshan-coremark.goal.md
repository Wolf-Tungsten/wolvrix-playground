## 节点：唯一粒度与固定流程

每次 `/goal` 完成一个节点，依次走完四个固定阶段，不得拆分、跳过或跨 `/goal` 分摊。每个阶段完成即在报告头部更新对应状态：

1. **基础选定**（状态 `BASELINE`）：决策父节点（默认当前最佳；选历史节点须给一句迂回理由）；核对输入与基线测量（配置未变时复用父节点归档值，不重跑）；确定资源配置、计时边界与止损线。
2. **假设提出**（状态 `HYPOTHESIS`）：陈述假设、创新点与瓶颈证据；给出假设关注的**微观指标**及其与总目标的定量关系（须有本分支实测数据支持，指标定义与基线值写入报告）；预注册：微观指标改善的判定阈值与测量方法、最终性能回退预算、证伪标准。
3. **代码实施**（状态 `IMPLEMENTED`）：实现方案，记录语义约束和与父节点的差异，通过聚焦测试（如 `make run_hdlbits_test DUT=001`）。
4. **结果测试**（状态 `TESTED`）：全流程门槛（生成/编译各 `<1800 s`）、100k 等价检查、微观指标测量、最终性能测量（一律 6 次交替复测登记，即便允许回退也要定量记录回退幅度）；随后进入判定。

## 判定与状态

节点内部状态 = 四个过程状态 + 两个终态。过程状态按固定流程顺序推进，逐阶段记录于报告；中断恢复后从报告记载的状态继续，不得把中断当作节点完成。

- 过程状态：`BASELINE` → `HYPOTHESIS` → `IMPLEMENTED` → `TESTED`（含义同四阶段）。
- 终态：`ACCEPTED` 或 `REJECTED`。

### 验收标准（`ACCEPTED`）

节点目标不是直接改善最终性能，而是改善假设关注的微观指标：

- 微观指标达到预注册改善标准，且正确性与生成/编译门槛通过。**最终性能允许回退**（作为扰动避免局部最优），但不得突破预注册回退预算；实际最终性能如实记入索引。
- 微观指标必须长远有利于总目标：假设提出阶段须给出该指标与仿真性能的定量关系（实测数据支持）；凭空造指标不允许。诊断/画像节点以交付定量指标基线为 `ACCEPTED`。

### 负向结果与 `REJECTED`

微观指标未达预注册标准，或回退突破预算，即为负向结果。结果测试阶段必须追加**定量复盘**，并二选一给出判断：

- **实现瑕疵**：证据表明假设成立而实现有误 → 回到 `IMPLEMENTED` 修正后重测（同一节点内）；正确性/门槛失败（`INVALID` / `TIMEOUT_KILLED` / `REGRESSION_KILLED`）默认按实现瑕疵处理；
- **机制性错误**：证据表明假设在机制层面不成立 → 节点以 `REJECTED` 收尾。**复盘分析是 `REJECTED` 判定的必要组成部分**，附在结果测试一节（数据、归因、机制性判定依据），结论登记到索引的机制证伪表，防止后续节点重复进入。`REJECTED` 节点保留在树中作为知识，其分支不再延伸。

## 节点树与迂回组合

- 节点以父指针组成树：每个节点在基础选定阶段声明父节点；索引逐节点记录父指针、锚定指标、判定与最终性能。
- 允许迂回：可从任意历史节点分叉；也允许把多个已 `ACCEPTED` 分支的改动组合为一个新节点（组合本身即该节点的假设）。
- 索引维护**当前最佳指针**（当前配置下最终性能最优的节点）。总目标的进展以当前最佳衡量；回退分支不更新指针，但可在后续节点中被重新接引。
- 物理提交在当前分支顺序进行；以非最新节点为父时，须在复现方法中记录父节点代码状态如何重建（revert/挑选清单），保证可复现。

## 执行与验证

所有构建、安装、生成、测试和仿真均通过 Makefile 目标；缺少目标时先补充，禁止手拼底层命令。常用目标为 `xs_wolf_grhsim_ir`、`xs_wolf_grhsim_ir_build_emu`、`run_xs_wolf_grhsim_ir_emu`，以当前 Makefile 为准。

每个节点有唯一 ID，每次实验有唯一 `RUN_ID`。日志和临时产物放 `ptmp/`，不写 `/tmp`。仿真固定 CPU 并显式设置 `XS_EMU_THREADS=1`；编译按机器实际核数并行（默认 `VM_BUILD_JOBS=$(XS_VM_BUILD_JOBS)` = `nproc`），节点文档须记录实际 job 数。

| 区间 | 计时边界与门槛 |
|---|---|
| SV→C++ 生成 | Make 启动至完整目标 C++ 和 Makefile 生成完成，墙钟 `<1800 s`；恢复已有 IR 的时间不能替代完整 SV 路线 |
| C++ 编译 | 编译目标启动至 emu 可执行文件完成，墙钟 `<1800 s` |
| 仿真 | 仅 emu 执行区间；记录 Host/墙钟时间、cycle 上限、退出状态及等价性 |

截止机制：生成或编译达 1800 s 立即终止该步骤及子进程，记 `TIMEOUT_KILLED` 并隔离未完成产物；仿真达预选可比较基线的 1.5 倍立即终止进程树，记 `REGRESSION_KILLED`。基线有多次测量时须在运行前选定比较值。退出非零、崩溃、断言失败、difftest mismatch 或输入不一致均记 `INVALID`；失败或部分结果只能用于原因分析。

比较口径：机器、输入、CPU 绑定、cycle 范围和 waveform/trace 设置一致；**每次运行前以 posix_fadvise 驱逐 page cache**（页帧固定偏差实测可达 ±6–9%）。配置未变时复用已归档 gsim 测量；配置变化时重建基线。采样/插桩时间不得混入未插桩性能基线。

时间类测量（最终性能及时间类微观指标）统一为 **6 次新旧交替复测**：同一时间窗口内交替执行新、旧构建（3 新 + 3 旧），运行前预注册执行顺序与比较口径，记录全部 6 次的 Host/墙钟时间、退出状态与等价性；任一构建出现 `INVALID` 该次作废补跑，两组各保持 3 次有效。报告两组均值、离散度与效应量；秩次判据：全部 3 次新运行均优于全部 3 次旧运行（n=3+3 等价 Mann-Whitney U 单侧 p≤0.05）方可判定提升真实。约 90 分钟尺度的机器漂移可达 ~4%，禁止用跨窗口或非交错历史数据充当对照。计数类确定性指标（固定输入下的动态计数等）可用精确比对，但须说明确定性来源。
