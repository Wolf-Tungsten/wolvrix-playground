数据来源、校验与编号口径

每个周期都有上升沿与下降沿；保留全部记录，未按耗时筛选周期。每个分区记录 input、eval、update 的原始纳秒耗时，复用了现有时钟读取；记录在 callback 计时区间外写入内存，进程退出时统一落盘。记录动作仍可能影响缓存、同步和运行时间。

两对新采集按 F→G、G→F 执行，功能签名、运行参数、代码页配置均验证通过。生成时逐项检查时钟沿、复位边界、记录完整性和 callback 不超出全局阶段，并将所有逐步耗时之和与本次原始 timing JSONL 累计值核对（容许 JSON 小数舍入）。仅外围 4 个目标文件加入记录，各自 7450 个其他目标文件字节不变，原性能二进制未改动。

整周期 = 上升沿 + 下降沿；“第 1 对”与“第 2 对”均为真实独立运行，而非均值。F/G 的同周期对照表示相同逻辑进度的两次独立采样，不代表同时发生。G 仍是含非默认选项的保留验证线。

所有数据已按周期区块压缩内嵌，可离线打开，不需要服务器或网络。浏览器只解压当前区块；首次打开文件可能需要几秒。需要支持 DecompressionStream 的现代浏览器。

时间精度：原始记录为 ns，显示到 0.001 µs；导出 CSV 同时保留原始 ns。页面中的 input / eval / update 开关只影响图形，不删除数据。
